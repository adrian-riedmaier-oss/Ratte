Modell

Mehrere Modellfamilien treten bei jedem Laden neu gegeneinander an. Bewertet wird per Kreuzvalidierung: ein zusammenhängender Abschnitt der Messreihe wird weggelassen und dann vorhergesagt. Gewonnen hat die Familie mit dem kleinsten Fehler auf ungesehenen Schüssen; bei statistischem Gleichstand die sparsamste. Solange ein Seil noch wenige Schüsse hat, tritt zusätzlich die Kurvenform des vorherigen Seils an — verschoben und gestreckt.

GitHub-Zugang

        

          Sobald ein Token hinterlegt ist, sichert die Konsole jeden Schuss von
          selbst ins Repository — kurz verzögert, damit eine schnelle Folge von
          Schüssen zusammen committet wird.
        

        

          Token auf GitHub erzeugen
          — fine-grained, unter Repository access nur dieses
          eine Repository, und unter Permissions → Contents auf
          Read and write stellen. Mehr braucht er nicht.
        

        

          Der Token bleibt ausschließlich in diesem Browser (localStorage) und
          steht nicht im Seitenquelltext — Besucher der Seite sehen ihn nicht.
          Ohne Token funktioniert alles andere weiter: die Schüsse liegen dann
          lokal und lassen sich als CSV exportieren.
